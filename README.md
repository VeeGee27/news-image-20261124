## The image

`main.py` draws `entry.png` (1024×1024, PNG) with the Python standard library plus Pillow. It writes to `$MAKEFUN_OUTPUT_DIR` when set, otherwise to the directory holding `main.py`. Run it twice and the bytes are identical.

```
python3 main.py
```
